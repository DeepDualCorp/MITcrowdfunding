MY ACTIVITIES

For the last 6 months, I have been working on creation a new branch of mathematics - nilpotent analysis. This branch is able to create most universal differentiation method, that can be fully automatic and useful for functions based on any set, even if this set is non-associative (e. g. octonions, sedenions) either non-archimedean (e. g. hyperreal, superreal, surreal numbers) or anything else, using the nilpotent properties of an unique type of numbers I discovered.

In the next few months, I will publish a scientific paper on this topic.

I'm also managing the development of a DeepDual Core - a huge, non-commercial, free computational math ecosystem (C++) based on nilpotent analysis, category theory, geometric algebra, hypercomplex numbers and a lot more.

This system isn't done yet and have only very small prototype DeepDual Core v0.1.0-pre-alpha, that's already published on GitHub: https://github.com/DeepDualCorp/DeepDual-Core. This version isn't release and includes only functions based on real (and, in partial, rational) numbers, dual numbers, Kolmogorov-Arnold Networks (KAN) and automatic mixed-differentiation of any functions based on real numbers.
